# Harmonizing Next Feature Roadmap

This roadmap keeps stable feature names for upcoming work. When you are ready to start one, use the name directly, for example: `Start Teacher Prep Dashboard`.

## Recommended Order

1. Timestamped Video Feedback
2. Parent Guardian Portal
3. Class Credit Ledger
4. Weekly Family Digest

## Completed Features

- Teacher Prep Dashboard

## Named Feature Plans

### 1. Teacher Prep Dashboard

Status: Completed.

A pre-class workspace that shows the teacher everything needed before a lesson: last lesson notes, active repertoire, homework, recent videos, practice logs, current level, and suggested focus.

### 2. Parent Guardian Portal

Add parent/guardian accounts so families can view schedule, reports, consent, invoices, practice assignments, messages, and progress without sharing the student login.

### 3. Timestamped Video Feedback

Let teachers leave feedback tied to exact video timestamps, such as `0:32` or `1:14`, so student video review feels music-specific and premium.

### 4. Class Credit Ledger

Track monthly class allowance, used classes, missed classes, makeup credits, extra classes, expiration, and admin adjustments while keeping billing external.

### 5. Curriculum Map

Create Piano and Voice curriculum paths by level so progress connects to clear academy milestones, skills, repertoire expectations, and level advancement.

### 6. Weekly Family Digest

Send a weekly email summary to families with completed classes, homework, next class, practice activity, teacher comments, and important reminders.

### 7. Practice Timer And Streaks

Add a simple student practice timer tied to assignments, with streaks, weekly minutes, and motivational progress tracking.

### 8. Recital Performance Mode

Track recital/performance pieces, readiness, backing tracks, teacher notes, student videos, and performance dates.

### 9. Catalog Sheet Attachments

Allow sheet music and reference materials to live on global catalog songs, so teachers can reuse materials when assigning songs to students.

### 10. Admin Health Dashboard

Add an operational dashboard for missing consent, failed emails, students with no activity, missing timezones, no teacher assignment, blackout conflicts, and other admin risks.

## Notes

- Each roadmap item should get its own detailed implementation plan before coding begins.
- These names are intended to stay stable so they can be referenced in future work requests.
- Roadmap order can change based on pilot feedback.
